# Reference Song Analysis

## Accept references

Accept a title plus artist/version, URL, audio file, video, user-supplied lyrics, live version, prior user work, or multiple references. Confirm the version only when ambiguity changes the analysis.

Use available tools to inspect accessible material. Separate observed evidence from inference. If only lyrics are available, analyze lyric structure and writing but do not claim to hear melody, instrumentation, vocals, or mix. If only a title is supplied and lookup is unavailable, ask for a link, file, or the user's description.

## Map structure

Identify:

- Intro and first-vocal entry.
- Verse, Pre-Chorus, Chorus, Hook, Bridge, breaks, instrumental sections, Final Chorus, and Outro.
- Relative section length and repetition.
- Hook placement.
- Final-Chorus development.
- Ending behavior.

Describe function in plain language, for example:

```text
short intro → restrained narrative Verse → rising transition → title-led Chorus → more specific second Verse → repeated transition → widened Chorus → one perspective-changing Bridge → intensified final Chorus → short ending
```

## Analyze why it works

Cover only dimensions supported by the material:

- **Lyric function**: scene establishment, new information, emotional lift, central statement, reversal, resolution.
- **Imagery**: time, place, people, actions, sensory details, recurring objects, and transformed meanings.
- **Hook mechanics**: title relation, length, placement, repetition, conversational form, contrast, question, number, or standalone shareability.
- **Language rhythm**: line length, density, parallel syntax, rhyme, stress, and Verse/Chorus contrast.
- **Music**: tempo, groove, melodic contour, tonal behavior, instrumentation, arrangement, vocal dynamics, harmonies, mix, and space—only when audible evidence is available.

Explain mechanisms rather than merely labeling a song “sad,” “pop,” or “good.”

## Build a transferable profile

Summarize reusable mechanisms:

```text
Use its short opening, two information-advancing Verses, rising transition, title-centered Chorus, concrete everyday objects, restrained-to-open emotional curve, and clean vocal-forward production. Do not copy its lyrics, melody, signature phrasing, or identity-dependent voice.
```

Let the user select which dimensions to transfer. Treat a late reference as a scoped revision unless the user requests a full reset.

## Combine multiple references

Assign roles instead of merging every feature:

```text
Reference A: structure and Chorus entry
Reference B: vocal texture and delivery
Reference C: instrumentation and mix space
```

Flag incompatible combinations and propose a dominant reference when needed.

## Avoid imitation

Transfer structure proportions, emotional movement, narrative method, image strategy, hook mechanism, groove, instrument roles, vocal dynamics, and spatial production. Do not reproduce lyrics, near-paraphrase distinctive lines, copy melody, reproduce signature phrases, or rely on a named singer's identity-specific voice.

## Output analysis

Use:

```markdown
## 参考曲结构

结构地图与段落功能。

## 好听机制

- Hook
- 情绪推进
- 具象意象
- 语言节奏
- 可证实的音乐与制作机制

## 可迁移特征

抽象原创机制。

## 不直接复制的部分

歌词、旋律、标志性表达或身份化声线。

## 新作品建议

结构、歌词、Style 与创新空间。
```
